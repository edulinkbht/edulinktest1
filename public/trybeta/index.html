How to Fix Firebase Permission Error

`allow read, write: if false;` solution guide

Your Firebase database currently rejects queries because the default Firestore Rules set read and write permissions to false.

Step 1: Copy Updated Rules 
rules_version = '2';

service cloud.firestore {
  match /databases/{database}/documents {
    match /{document=**} {
      // Allows logged-in authenticated users to read and write
      allow read, write: if request.auth != null;
    }
  }
}
Step 2: Update in Firebase Console
  1. Go to Firebase Console and open your project idembt.
  2. Click on Firestore Database on the left navigation menu.
  3. Click the Rules tab at the top.
  4. Replace allow read, write: if false; with allow read, write: if request.auth != null; (or paste the copied snippet above).
  5. Click Publish!
